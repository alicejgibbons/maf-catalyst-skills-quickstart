# Aurora-9 Connector — Compatibility Notes

The Aurora-9 Connector (SKU ARC-9X-4471) is rated compatible with exactly these three components —
this list is invented for a skills-loading test and only exists in this file:

- **Meridian-4 Hub** (full support, no adapter needed)
- **Solstice Rail v2** (requires the SL-ADPT-02 adapter, sold separately)
- **Vantage Bridge** (firmware 3.x or later only — firmware 2.x is NOT supported)

It is explicitly NOT compatible with the "Legacy Aurora-3 Hub" — do not recommend that pairing.
